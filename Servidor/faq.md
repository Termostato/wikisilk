# FAQ

¿Tienes más preguntas? Iremos actualizando las preguntas más frecuentes.

## ¿Cómo cambio mi contraseña en el servidor?

Es muy sencillo, usa el comando **`/changepassword (antigua contraseña) (nueva contraseña)`**

### Pasos a seguir:

1. Coloca tu contraseña antigua (por ejemplo: `Pepito123`)
2. Coloca tu contraseña nueva, que sea más segura (por ejemplo: `Pepito7682`)

### Ejemplo de uso:

```bash
/changepassword Pepito123 Pepito7682
```

::: tip
_¡Recuerda! Estos son solo ejemplos. Usa contraseñas seguras y únicas para tu cuenta._
:::

## ¿Cómo activar el modo premium?

Para activar el modo premium deberás usar dentro de los lobbies:

```bash
/premium [contraseña]
```

::: warning ADVERTENCIA
Solo para jugadores premium. Si usas el comando siendo no premium perderás el acceso al servidor.
:::

## ¿Cómo se vota en el servidor?

### Para jugadores Java:

1. Entra a **Survival** y usa el comando **`/vote40`**
2. Obtendrás un link, ábrelo y te llevará a la página para votar
3. Sigue estos pasos:
   - **Paso 2:** Pon tu nick
   - **Paso 3:** Espera la verificación
   - **Paso 4:** Finaliza el proceso
4. Haz clic en **"Votar"** y espera un minuto o dos
5. Usa **`/vote40`** nuevamente en el servidor y recibirás la recompensa

### Para jugadores Bedrock:

Si no puedes hacer clic en enlaces en el chat, deberás ir a nuestro [Discord](https://discord.silkcraft.net) y usar el comando **`!votar`** en cualquier canal.

## ¿Cómo se entra en Bedrock al servidor?

Sigue estos pasos para conectarte desde Bedrock Edition:

1. **Añadir nuevo servidor**
2. **Nombre del servidor:** Cualquier nombre (ejemplo: "SilkCraft")
3. **IP del servidor:** `mc.silkcraft.net`
4. **Puerto:** `19132` (déjalo como está)

::: info
El puerto **19132** es el puerto predeterminado para Bedrock Edition.
:::

## ¿Cómo se abre ticket en Discord?

Para abrir un ticket en Discord:

1. Ve al canal **`#tickets`** en nuestro [Discord](https://discord.silkcraft.net)
2. Selecciona la categoría que requieras
3. Responde las preguntas que te hace el bot
4. Un miembro del staff te responderá el ticket

::: tip
Mantén los MDs (mensajes directos) abiertos en Discord para que el staff pueda contactarte.
:::

## ¿Por qué no me llegó nada de lo que compré en la tienda?

Esto puede ocurrir por dos razones principales:

1. **Pusiste mal el nick** - Verifica que hayas escrito correctamente tu nombre de usuario
2. **Eres de Bedrock y no pusiste el punto** - Si eres jugador de Bedrock, debes poner el **`.`** (punto) al principio de tu nombre

### ¿Y ahora qué hago?

Deberás contactar con soporte en [Discord](https://discord.silkcraft.net) mediante el sistema de tickets para que te lo arreglen. Para las próximas compras ya sabrás qué hacer.

::: warning
Recuerda: Si eres de Bedrock, siempre incluye el punto (`.`) al inicio de tu nombre de usuario al hacer compras.
:::
